## Featured Projects

### Multi Agent Financial Portfolio Assistant

Built a financial analysis application using a six agent architecture to analyze 19 Asian technology stocks across four regions. Integrated retrieval augmented generation using FAISS and the Gemini API, with market data retrieval, portfolio analytics, and an interactive Streamlit interface.

**Technologies:** Python, Gemini API, FAISS, RAG, Streamlit, yFinance

**Repository:** [Multiagent_financial on github](https://github.com/Hareshganesan/Stock_Market_Predictor)

### Patient Level Retinal Disease Classification

Developed a deep learning framework to classify retinal OCT scans into CNV, DME, Drusen, and Normal categories. Investigated patient level data leakage in OCT2017 and evaluated performance using a patient independent split.

Reported results include 93.7% patient independent accuracy and an improvement in Attention Alignment Score from 0.630 to 0.967.

**Technologies:** Python, PyTorch, ResNet50, U-Net

**Repository:** [Retina on GitHub](https://github.com/Hareshganesan/Retina)

### Global Water Quality Retrieval
